# Requirements Document: Butterfly Symmetry Website (Black & Gold Edition)

**Version:** 1.0  
**Source site:** https://sites.google.com/student.sfbu.edu/khadiza-butterfly-symmetry/home  
**Deliverable:** A static website, publicly hosted on GitHub Pages.

## 1. Overview

Replicate the Google Sites project as a standalone static site with a black and gold theme.

## 2. Pages

1. Home (`index.html`)
2. Notice + Name (`notice-name.html`)
3. Explain the Mathematics (`explain-the-mathematics.html`)
4. CREATE (`create.html`)

## 3. Theme

- Background `#0A0A0A`, gold `#D4AF37`
- Playfair Display headings, Inter body
- Sticky header, mobile menu under 768px

## 4. Hosting

GitHub Pages from the `main` branch, folder `/ (root)`.
