# Butterflies and Mathematical Symmetry

A short static website about reflection symmetry in butterfly wings (black and gold theme).

**Live site:** https://abdur-rafey5.github.io/butterfly-symmetry/

## Tech

- HTML, CSS, and a little JavaScript
- Hosted on GitHub Pages

## Run locally

Open `index.html` in a browser (or use any simple static server).
